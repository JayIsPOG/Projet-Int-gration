# Projet-Int-gration
Projet d'intégration en Sciences, Informatiques et Mathématiques

La Crypte Mystérieuse est un jeu en deux dimensions avec une vue de haut dont le thème principal est un donjon. Le joueur aura à combattre des ennemis et à résoudre des énigmes et à battre un bot au backgammon pour compléter le jeu.

Trois parties composent le jeu:
- Des énigmes de lumière
- Des combats
- Une partie de backgammon contre un bot
